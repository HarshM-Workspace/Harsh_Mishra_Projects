## Engineering Focus

I’m especially interested in building systems around this flow:

```text
Sources
  │
  ├── APIs
  ├── Files
  ├── Events
  └── Application Data
        │
        ▼
    Ingestion
        │
        ▼
 Validation / Cleaning
        │
        ▼
 Transformation
        │
        ▼
   Data Storage
        │
   ┌────┴────┐
   ▼         ▼
Analytics   APIs
   │         │
   └────┬────┘
        ▼
 Dashboards / AI
```

The recurring theme across my projects is moving from **raw data → reliable data → useful system**.
