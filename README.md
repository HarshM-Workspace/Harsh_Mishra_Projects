## Projects

### [Labor Market Intelligence](./Labor-Market-Intelligence)

An ETL pipeline reconciling labor-market data across three independently-structured sources — the Stack Overflow Developer Survey, the Adzuna Jobs API, and the GitHub API — to track emerging tech trends. The core engineering challenge is entity resolution: matching the same underlying skill or technology as it's named differently across all three vocabularies.

**Stack:** Python 3.11, Dagster, dbt-core (dbt-duckdb), DuckDB/MotherDuck, GitHub Actions, Streamlit

See the [project README](./Labor-Market-Intelligence/README.md) for full details.
